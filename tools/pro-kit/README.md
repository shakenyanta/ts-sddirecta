# プロ版への切り替えセット

配布用の共通exeをプロ版として使うためのコピー用設定です。このセットはGit管理します。

## 使い方

1. 配置先の `ts-sddirecta.exe` を終了します。
2. このREADMEと同じ場所にある `.config` フォルダーを、exeと同じフォルダーへコピーします。
3. exeを起動し、タイトルが `ts-sddirecta pro` になり、SD MAPの「詳細」ボタンが表示されることを確認します。

```text
配置先/
├─ ts-sddirecta.exe
└─ .config/
   └─ edition.json
```

コピーするのは `.config` です。`pro-kit` フォルダーごと置いても版は切り替わりません。
既存の `.config` がある場合は、その中へ `edition.json` だけをコピーし、ほかのファイルは残してください。
既存の `edition.json` があれば内容を確認してから置き換えてください。
CSV用の `config` フォルダーとは異なります。

## ライト版へ戻す場合

配置先の `.config/edition.json` を次の内容へ変更して、アプリを再起動します。
ほかの設定を残すため、`.config` フォルダー全体を削除する必要はありません。

```json
{
  "edition": "lite"
}
```

## 管理・配布

- このセットは開発部署向けに別途渡します。通常のGitHub Releasesの添付やライト版の配布物には含めません。
- プロジェクト直下の実設定 `.config/edition.json` は引き続きGit管理対象外です。
- 配布用リリースビルドで使用します。開発起動の版は開発用環境変数で決まるため、このセットのコピーでは変わりません。
- 更新時は配置先の設定が保持されます。

詳しくは [ライト版・プロ版の開発方針](../../docs/editions.md) を参照してください。
